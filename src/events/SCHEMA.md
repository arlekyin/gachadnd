# События — формат

Одно событие — один файл `src/events/<id>.yaml`. Сборка (`npm run build`) проверяет файлы и собирает их в `data/events.json`; ошибка в файле останавливает сборку и называет поле.

Событие открывается у всех, когда отряд входит на узел «Событие»: разворот дневника — слева рисунок и подпись, справа запись и 2–3 варианта. Событие выбирается по биому и этажу из ещё не встречавшихся.

## Поля

| Поле | Обязательно | Что это |
|---|---|---|
| `id` | да | латиница в нижнем регистре, цифры и `_` |
| `title` | да | заголовок записи |
| `biome` | да | биом или список: `swamp` (лес и болота), `town` (город в глуши), `sea`, `storm`, `deep`, `sky`, `labyrinth` (этажи без биома), `any` |
| `floors` | нет | `[от, до]` — на каких этажах |
| `once` | нет | `false` — может выпадать повторно (по умолчанию — раз за забег) |
| `image` | нет | рисунок: `src` (путь от папки модуля, `assets/sketches/…`), `w`, `h` (размер в пикселях), `lights` — список `{ x, y, r }`: где на рисунке свет (огоньки, окна) |
| `sketch` | нет | зарисовка кодом, если рисунка нет |
| `caption` | нет | подпись почерком под рисунком |
| `text` | да | абзацы записи (1–4) |
| `options` | да | 2–3 варианта |

Рисунок — монохромный набросок на ровном белом фоне, без текстуры бумаги, рамок и подписей: фон модуль убирает, графит ложится на пергамент.

## Вариант

| Поле | Что это |
|---|---|
| `label` | что делает отряд |
| `detail` | цена и награда коротко (если нет и есть проверка — напишется сама: характеристика, навык, Сл) |
| `who` | кто делает: `one` — один персонаж (выбирается в строке «Кто»), `all` — весь отряд, `none` — никто |
| `check` | проверка — одно из: `skill` (навык dnd5e: `sur`, `ath`, `ste`…), `ability` (проверка характеристики: `str`…`cha`), `save` (спасбросок: `str`…`cha`); `dc` — поправка к Сл этажа (11 + этаж) |
| `text`, `effects` | без проверки: что случилось и исходы |
| `success`, `failure` | с проверкой: `{ text, effects }` на успех и провал |

## Исходы (`effects`)

Каждая запись — один исход; `to: one | all` — кому (по умолчанию — как `who` варианта).

| Исход | Значение |
|---|---|
| `gold: 0.2` | доля Базы этажа: плюс — получить, минус — заплатить (сколько есть) |
| `reward: { tier, count }` | карточки «Награды события»: `small`, `notable`, `rare`, `floor` |
| `crystal: { rarity, tag? }` | случайный кристалл этой редкости (и тега); `rarity: up` — на редкость выше отданного (после `take_crystal`) |
| `take_crystal: true` | забрать кристалл — самый дешёвый; `{ min: blue }` — не дешевле |
| `take_skill: { pay }` | забрать случайный навык Памяти и заплатить долю Базы × вес редкости (серый 1 … красный 8) |
| `burn_skill: true` | сжечь случайный навык Памяти |
| `cool: true` | снять перегрев и блок со всех навыков |
| `omen: 1` | предвестие Пожирателя ближе (`-1` — дальше); до прихода не доводит |
| `deal_preview: true` | открыть лоты следующей Сделки луны — Сделка этого этажа предложит именно их |
| `moon_mark: true` | метка луны на персонаже (флаг `moonMark`) |
| `skill: { rarity }` | случайный навык этой редкости сразу в Память |
| `hit_dice: -1` | плюс — вернуть потраченные Кости Хитов, минус — потратить |
| `hp: -0.25` | доля максимума ПЗ: плюс — лечение, минус — урон |
| `note: "…"` | напоминание Мастеру шёпотом (то, что модуль сам не ведёт) |
| `fight: "…"` | бой: кого выставить — подсказка Мастеру |

## Пример

```yaml
id: swamp_lights
title: Огоньки над трясиной
biome: swamp
caption: огоньки — не светлячки
text:
  - Над чёрной водой висят огоньки — неподвижно, будто ждут.
options:
  - label: Пойти за огоньками вглубь
    who: one
    check: { skill: sur, dc: 0 }
    success:
      text: Огоньки ведут к полузатопленной лодке.
      effects:
        - reward: { tier: notable, count: 3 }
          to: all
    failure:
      text: Трясина отпускает не сразу.
      effects:
        - hit_dice: -1
          to: all
  - label: Обойти трясину стороной
    who: none
    text: Огоньки провожают отряд взглядом.
```
