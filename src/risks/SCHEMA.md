# Схема испытаний Риска

Один файл — одно испытание. `node build.mjs` проверяет файлы и собирает их в `data/risks.json`.

| Поле | Обязательно | Значения |
|---|---|---|
| `id` | да | Латиница в нижнем регистре, цифры, `_`. Уникален. |
| `name` | да | Название испытания. |
| `intro` | да | Сцена, которую зачитывает Мастер. |
| `collapse` | да | Обвал после 3-го провала: `{ text, hp, condition }` — действует на всех персонажей отряда. |
| `stages` | да | Список этапов, не меньше 3. |

## Этап

| Поле | Значения |
|---|---|
| `name` | Название этапа. |
| `group` | `true` — групповой этап: бросают все, этап пройден, если преуспела хотя бы половина. |
| `approaches` | Подходы: `{ label, skill, dc, fail }`. |

- `skill` — навык dnd5e: `acr`, `ani`, `arc`, `ath`, `dec`, `his`, `ins`, `itm`, `inv`, `med`, `nat`, `prc`, `prf`, `per`, `rel`, `slt`, `ste`, `sur`.
- `dc` — поправка к Сл этажа (12 + половина номера этажа). Осторожный подход — ниже, дерзкий — выше.
- `fail` — `{ text, hp, condition }`: `hp` — множитель уровня персонажа (потеря ПЗ), `condition` — `prone`, `poisoned`, `frightened`, `blinded`, `deafened`, `restrained`.

Текст с запятой в однострочной записи `{ text: ... }` берите в кавычки.

## Награда этапов

Не задаётся в файле — одинакова для всех испытаний: ½ золота элитной комнаты → зелёный кристалл → синий → золото элитной комнаты → фиолетовый → далее синий и фиолетовый по очереди.
