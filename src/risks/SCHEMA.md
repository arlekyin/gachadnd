# Схема испытаний Риска

Один файл — одно испытание. `node build.mjs` проверяет файлы и собирает их в `data/risks.json`.

| Поле | Обязательно | Значения |
|---|---|---|
| `id` | да | Латиница в нижнем регистре, цифры, `_`. Уникален. |
| `name` | да | Название испытания. |
| `intro` | да | Сцена, которую зачитывает Мастер. |
| `collapse` | да | Обвал после 3-го провала: `{ text, hp, condition }` — действует на всех персонажей отряда. |
| `stages` | да | Список этапов, не меньше 3. |

## Этап

| Поле | Значения |
|---|---|
| `name` | Название этапа. |
| `group` | `true` — групповой этап: бросают все, этап пройден, если преуспела хотя бы половина. |
| `approaches` | Подходы: `{ label, skill, dc, fail }`. |

- `skill` — навык dnd5e: `acr`, `ani`, `arc`, `ath`, `dec`, `his`, `ins`, `itm`, `inv`, `med`, `nat`, `prc`, `prf`, `per`, `rel`, `slt`, `ste`, `sur`.
- `dc` — поправка к Сл этажа (12 + половина номера этажа). Осторожный подход — ниже, дерзкий — выше.
- `fail` — `{ text, hp, condition }`: `hp` — множитель уровня персонажа (потеря ПЗ), `condition` — `prone`, `poisoned`, `frightened`, `blinded`, `deafened`, `restrained`.

Текст с запятой в однострочной записи `{ text: ... }` берите в кавычки.

## Награда этапов

Не задаётся в файле — одинакова для всех испытаний: ½ золота элитной комнаты → зелёный кристалл → синий → золото элитной комнаты → фиолетовый → далее синий и фиолетовый по очереди.

## Свои испытания Мастера

Испытания можно добавить без сборки модуля: положите JSON-файл в данные мира (например `worlds/<мир>/risks.json`) и укажите его в настройке модуля «Свои испытания Риска». Файл — один объект испытания или список. Модуль проверяет его по тем же правилам, что и сборка: испытание с ошибкой пропускается, Мастер видит уведомление с полем ошибки. Настройка «Только свои испытания Риска» отключает встроенные.

```json
[
  {
    "id": "my_swamp",
    "name": "Трясина",
    "intro": "Земля под ногами чавкает и тянет вниз.",
    "collapse": { "text": "Трясина смыкается над головами.", "hp": 2, "condition": "restrained" },
    "stages": [
      { "name": "Кочки", "approaches": [
        { "label": "Прыгать по кочкам", "skill": "acr", "dc": 1, "fail": { "text": "Нога уходит в топь.", "hp": 1, "condition": "restrained" } },
        { "label": "Прощупывать шестом", "skill": "sur", "dc": -1, "fail": { "text": "Шест ломается, падение в грязь.", "hp": 2 } }
      ] },
      { "name": "Пиявки — все вместе", "group": true, "approaches": [
        { "label": "Терпеть", "skill": "ath", "fail": { "text": "Пиявки пьют кровь.", "hp": 1 } }
      ] },
      { "name": "Огоньки на болоте", "approaches": [
        { "label": "Не идти за огоньками", "skill": "ins", "fail": { "text": "Огоньки уводят в трясину.", "hp": 2 } }
      ] }
    ]
  }
]
```

## Кнопки Мастера в окне Риска

- **Автоуспех** — творческое применение навыка, заклинания или предмета удалось: этап пройден, награда в копилке.
- **Автопровал** — импровизация не удалась: провал этапа, выступавший теряет ПЗ, равные уровню, и пропускает следующий этап. На групповом этапе — провал без урона.
- **Уйти с добычей** — копилка уходит персонажу из списка «Добыча».
