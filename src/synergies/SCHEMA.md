# Схема синергий тегов

Один файл — один тег. `node build.mjs` проверяет файлы и собирает их в `scripts/synergy-tiers.js` (не редактировать вручную). Теги навыков проверяются по этому списку.

| Поле | Значения |
|---|---|
| `tag` | Тег, как он пишется у навыков. |
| `key` | Латинский ключ для формул: `@flags.gachadnd.counts.<key>` — число экипированных навыков с тегом. |
| `icon` | Иконка эффекта и способностей. |
| `tiers` | Пороги: `{ count, name, description, changes, feature }`. |

## Порог

- `count` — сколько экипированных навыков с тегом нужно (обычно 2, 4, 6).
- `name` — название; к нему добавляется «Тег I/II/III:».
- `description` — текст по стандарту навыков: ПЗ, долгий отдых, формулы словами, «универсальная Сложность». Сборка не пропустит «HP», «за этаж», «длинный отдых».
- `changes` — Active Effect, как у навыков: `{ key, mode, value }`. **Эффекты всех достигнутых порогов складываются.**
- `feature` — способность на листе персонажа (кнопка в Терминале).

## feature

| Поле | Значения |
|---|---|
| `activation` | `action`, `bonus`, `reaction`, `special` |
| `uses`, `recovery` | Заряды: число или `prof` (бонус мастерства); перезарядка как у навыков: `short`, `long`, `combat`, `turn`, `round` |
| `range` | Дальность в футах |
| `target` | Область `{ type, value }`: `radius`, `sphere`, `cone`, `line`, `cube`, `cylinder` |
| `save` | `{ ability, on_save }` — спасбросок против универсальной Сложности; `on_save`: `half`, `none`, `full` |
| `damage` | Список `{ formula, type }` — урон при спасброске или без него |
| `heal` | `{ formula, type }` — лечение носителя; `type: temphp` — временные ПЗ |
| `roll` | `{ formula, name }` — бросок без урона (например, уменьшение урона) |

Заряды тратит первое действие способности.

## Универсальная Сложность

8 + бонус мастерства + наивысший модификатор характеристики + бонус синергий (Разум I: +1). Бонус хранится во флаге персонажа `dc_bonus`; его пишет расчёт синергий при каждом изменении экипировки и при запуске мира.
