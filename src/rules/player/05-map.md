# Карта этажа и узлы

Карта открывается кнопкой **Карта этажа** на панели токенов. Отряд по ней переводит Мастер, а узел, на который вошёл отряд, сам открывает своё окно у всех игроков.

**Куда идти.** Щёлкните любой узел карты, даже тот, до которого за один шаг не дойти. Вокруг него появится ваш портрет, и его увидят все. Повторный щелчок снимает отметку, щелчок по другому узлу переносит её. Это только ваш голос, решение за отрядом и Мастером. После шага отметки гаснут.

Карта прокручивается колесом и сама встаёт на отряд. Жирный пунктир — куда можно пойти сейчас, тонкая линия — куда ещё можно дойти, бледное — туда уже не попасть. Значки узлов объяснены в легенде внизу.

| Узел | Что происходит |
|---|---|
| Вход | начало этажа |
| Монстры | бой, за него золото и кристаллы |
| Элита | трудный бой, больше кристаллов и золота; перед ним отряд выбирает **обеты** |
| Событие | страница дневника: что вы видите и 2–3 варианта с ценой. Решаете вслух, проверки бросаете сами |
| Риск | испытание навыков в духе «испытай удачу», см. [[Риск]] |
| Магазин | торговец Тумана: кристаллы, расходники, предметы, услуги, см. [[Магазин и золото]] |
| Привал | короткий отдых; за кристаллы можно открыть портал в Якорь |
| Погибель | Алтарь Погибели: жертва ПЗ и кони всадников, см. [[Погибель и всадники]] |
| Застава | середина этажа, все пути сходятся на элитном бою; после победы вы получаете уровень |
| Босс | финал этажа; после победы уровень, долгий отдых и Сделка луны |

Узел Погибели встречается не на каждом этаже и не чаще одного раза.

## Обеты Элиты

Когда отряд входит на Элиту, у всех открывается окно с обетами. Обеты — это усложнения боя, по два случайных из каждой группы: способности, враги, количество, поле боя. Отмечать их может каждый, поэтому решайте вслух. Когда решите, нажмите **Готовы**, а в бой отряд ведёт Мастер. Чем больше сумма весов (ромбы у обета), тем больше награда, но только за победу.

| Сумма весов | Кристаллов на игрока | Ещё |
|---|---|---|
| 0 | 1,5 | — |
| 1–2 | 2 | — |
| 3–4 | 2,5 | — |
| 5–6 | 2,5 | золото ×1,5, один кристалл не ниже синего |
| 7 и больше | 2,5 | золото ×2, один кристалл не ниже фиолетового |

| Группа | Обет | Вес | Что делает |
|---|---|---|---|
| Способности | Голодный Туман | 1 | В конце боя каждый герой теряет по заряду с каждого надетого навыка, который не применял в этом бою |
| | Провал в Памяти | 2 | Один случайный надетый навык у каждого спит весь бой, пассивные тоже |
| | Потухшие грани | 2 | Камни Огранки в этом бою не работают |
| | Разорванные нити | 3 | Синергии в этом бою на ступень ниже |
| Враги | Закалка | 1 | Вожак получает +50 % ПЗ |
| | Месть стаи | 2 | Когда враг гибнет, ближайший к нему другой враг получает временные ПЗ: четверть максимума ПЗ павшего |
| | Не упокоен | 2 | Первый убитый враг встаёт в конце раунда с половиной ПЗ |
| | Засада | 3 | Весь первый раунд отряд пропускает: без ходов и без реакций |
| Количество | Подмога | 1 | +1 рядовой на каждых двух героев |
| | Густая стая | 2 | +1 рядовой на каждого героя |
| | Вторая волна | 2 | На 3-м раунде приходит по 1 рядовому на героя, за спиной отряда |
| | Второй вожак | 3 | В составе два вожака |
| Поле боя | Непогода | 1 | Погода будет точно |
| | Клещи | 1 | Часть стаи заходит с флангов |
| | Теснина | 2 | Поле 20 × 14 клеток вместо 28 × 20 |
| | Смыкание | 3 | Со 2-го раунда туман каждый раунд сжимает поле на клетку; герой за его границей в начале хода получает урон |

Подмога и Густая стая не складываются: выбор одной снимает другую. Обет, который отряду ничего не стоит, не выпадает. Допустим, камней ни у кого нет, тогда Потухших граней не будет.

## Паутина

Мастер может начертить этаж **паутиной**. Это неровная сеть узлов вокруг Босса, с ветками, обходами и тупиками. Открывается она той же кнопкой **Карта этажа** и занимает левую часть экрана. Узлы — кристаллы цвета своего типа, отряд — янтарный фонарь. Янтарные нити показывают, куда можно шагнуть. Пройденный кристалл потух и треснул. Наведите на кристалл, и увидите, что в нём.

- **Вход** — любой узел внешней зоны, на выбор отряда.
- **Заставы** — единственный путь из внешней зоны во внутреннюю. Взяли Заставу — получили уровень, как на обычной карте.
- **Шаг** — это переход на соседний узел. Пройденный узел пуст, но за один шаг по пройденным узлам можно пройти до трёх подряд.
- **Часы этажа.** Каждый шаг — это тик. После 12 шагов тишины Босс крепнет каждые 2 шага: Глушитель, Крайний спит, Окрепший (+25 % ПЗ), Свита. Часы нарисованы на ободе астролябии. Наведите на Босса или медальон, чтобы увидеть ступени.
- **Добыча с Босса растёт вместе с ним.** За каждую набранную ступень он даёт ещё один кристалл, а если набрал все, один из них будет фиолетовым.
- **Пожиратель на карте.** Когда Запах дошёл до Охоты, он выходит на край паутины и идёт к отряду. Чем он сытее, тем быстрее, до трёх узлов за шаг. Его следующий шаг видно заранее: нить окрашена до середины. Где он ступил, узел **съеден**. Соседний узел, который он **тронул**, темнеет и съедается через 2 шага. Съеденный узел пуст, и вход в него — это прорыв, как и встреча с самим Пожирателем. Победили его — 4 шага он никого не ест.
- **Заставы держат Пожирателя**, пока вы через них не прошли. После этого он проходит её и съедает, как любой узел.

Сколько бродить, решайте сами. Лишние узлы дают добычу, но каждый шаг кормит Босса и даёт время Пожирателю, а из тупика придётся возвращаться.

## Летопись этажа

Когда Мастер чертит следующий этаж, открывается дневник Разлома. Лист старой карты в последний раз показывает ваш путь: где сгорели навыки, где остались павшие, где прорывался Пожиратель, что взяла луна. Потом страница перелистывается на новый этаж. Щелчок пропускает эту сцену.

## Сделка луны

После победы над Боссом луна предлагает обмен. У неё три лота: копия навыка товарища, сплав двух навыков в один слот, помощь Босса или Пожирателя на следующем этаже. Купить или выбить такое больше негде.

Платите вы жертвами, и весы общие: навык, Кость Хитов или пять ПЗ максимума навсегда, слот Памяти, кристалл из Хранилища, золото. Когда набрали цену, луна становится полной, и Мастер скрепляет сделку печатью. Только тогда жертвы списываются. Можно и отказаться, тогда никто ничего не теряет.

Отголосок Босса и Пожиратель приходят в бой на следующем этаже, когда вы попросите Мастера. Отголосок ходит сразу после позвавшего и рассыпается. Пожиратель два хода рвёт врагов и забирает себе кристалл из добычи этого боя.
