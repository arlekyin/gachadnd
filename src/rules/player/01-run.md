# Забег

Лабиринт состоит из этажей. Каждый этаж — карта узлов от Входа до Босса. Отряд выбирает путь по связям между узлами и проходит этаж за этажом.

- Забег рассчитан на **10 этажей**. За каждый пройденный этаж персонажи получают уровень.
- Номер этажа виден над картой этажа. От него зависят награды, цены и Сложность испытаний.
- **Долгий отдых** — только после победы над боссом этажа.
- **Короткий отдых** — только на узле Привал.

## Якорь

Каждая сессия начинается в **Якоре** — лагере под куполом вероятности в Пределе. Голодные души Предела остаются за его границей.

- В Якоре открыт Алтарь Памяти: можно проводить ритуалы и менять навыки.
- Кости Хитов в Якоре не восстанавливаются, короткого отдыха нет.
- Первый шаг по карте этажа уводит отряд из Якоря.

Окна модуля открываются кнопками на панели токенов: **Карта этажа**, **Терминал Тумана** (Память персонажа) и, у Мастера, **Генератор добычи**.
