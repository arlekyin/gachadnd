# Риск

Испытание навыков вне боя. Награда копится в общей **копилке**, и перед каждым этапом отряд решает: идти дальше или **уйти с добычей**.

## Этап

- **Выступает один персонаж** — отряд выбирает кого. Подходы этапа предлагают разные навыки и Сложность.
- **Один союзник может помочь** — бросок с преимуществом. Помощник в этом этапе не выступает.
- **Выступавший пропускает следующий этап.**
- **Групповой этап** бросают все; этап пройден, если преуспела хотя бы половина.
- Сложность: 11 + номер этажа, плюс поправка подхода.

## Провал

- Последствия провала (ПЗ, состояние) получает выступавший.
- **Цена крови:** после провала можно потратить Кость Хитов и добавить её результат к броску.
- **3 провала — обвал:** копилка сгорает наполовину, весь отряд получает последний удар сцены.

## Копилка

| Этап | Награда |
|---|---|
| 1 | половина золота элитной комнаты |
| 2 | зелёный кристалл |
| 3 | синий кристалл |
| 4 | золото элитной комнаты |
| 5 | фиолетовый кристалл |
| 6+ | синий и фиолетовый по очереди |

## Во время испытания

- Нельзя поглощать кристаллы и менять навыки.
- Нельзя отдыхать; Кости Хитов — только на Цену крови.
- Можно использовать экипированные навыки, заклинания и (между этапами) расходники. Творческое применение может засчитать этап без броска.
- Решение уйти принимается большинством; при равенстве отряд уходит.
- Персонаж на 0 ПЗ выбывает из испытания.
