# Термины

| Термин | Что значит |
|---|---|
| ПЗ | пункты здоровья |
| КХ | Кости Хитов; лечат на коротком отдыхе и оплачивают ритуалы Алтаря |
| Память | все навыки персонажа, до 20 |
| Слот | одно место под надетый навык |
| Предел разума | сколько слотов занято и сколько есть |
| Надеть | поставить навык в слот; действуют только надетые навыки |
| Кристалл | навык в инвентаре, пока его не поглотили |
| Вес кристалла | сколько кристалл пахнет; им же платят за портал и откуп |
| Запах | сумма весов кристаллов в сумках отряда; на него идёт Пожиратель |
| Пожиратель | существо, которое охотится за кристаллами отряда |
| Хранилище | личный тайник у Алтаря; кристаллы в нём не пахнут |
| Сожжение | навык удалён из Памяти навсегда |
| Ранг | сила навыка; растёт слиянием повторов в Якоре |
| Заряд | сколько раз можно использовать навык до восстановления |
| Заёмный заряд | заряд, который навыку вернул другой навык |
| Перегрев | риск сжечь навык заёмными зарядами |
| Эхо | следы прежних владельцев навыков, копятся от использования |
| Тег | метка навыка: огонь, кровь, сталь и другие |
| Синергия | эффект 2, 4 или 6 одинаковых тегов у надетых навыков |
| Связка | способность, которую дают по 2 навыка двух разных тегов |
| Камень | вставляется в оружие или категорию способностей и меняет, как они работают; разрешает его ступень синергии |
| Огранка | вставка камней в оружие и категории способностей |
| Уникальный | фиолетовый, красный или оранжевый навык: рангов нет, повтор не поглощается |
| Штраф | цена сильного навыка, указана в его описании |
| Шрам | навык-рана: занимает слот, снять нельзя, лечится |
| Узел | точка на карте этажа: бой, Магазин, Привал и так далее |
| Обет | усложнение боя на Элите за большую награду |
| Якорь | лагерь между этажами, где открыт Алтарь Памяти |
| Копилка | награда испытания Риска, которая копится по этапам |
| Цена крови | Кость Хитов, добавленная к проваленной проверке Риска |
| Универсальная Сложность | 8 + бонус мастерства + наивысший модификатор характеристики |
| Вероятность | сила существ, знающих, что они в лабиринте: так они слегка меняют его |
