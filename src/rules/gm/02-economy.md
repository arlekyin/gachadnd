# Экономика

Модуль считает всё сам, глава нужна, если хочешь поправить баланс. Всё идёт от **базы этажа**: База(Э) = 100 × 2,25^(Э − 1). Этаж — это два уровня, то есть рост 1,5 за уровень.

| Что | Формула |
|---|---|
| Монстры | База × 0,05–0,15 |
| Элита | База × 0,2–0,5 (с обетами золото до ×2) |
| Босс | База × 0,7–1,0 |
| Кристалл в магазине | База × 0,2 / 0,5 / 1,2 / 3 (серый / зелёный / синий / фиолетовый) |
| Очистка | База × 0,5 × (1 + очисток персонажа за забег) |
| Обновление ассортимента | База × 0,2 × (1 + обновлений в этом магазине) |
| Магические предметы | цена из предмета; без цены — DMG 2024: 100 / 400 / 4 000 / 40 000 зм, расходники вдвое дешевле; в продаже необычные со 2 этажа, редкие с 4-го, очень редкие с 6-го |

Золото комнаты Генератор добычи зачисляет выделенному токену, это доля всего отряда. Если токен не выделен, сумма только показывается в карточке, и делишь её ты.
