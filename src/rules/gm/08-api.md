# Макросы и настройки

## Макросы

| Команда | Действие |
|---|---|
| `game.gachadnd.openTerminal(actor)` | Терминал Тумана персонажа |
| `game.gachadnd.openMapTerminal()` | Карта этажа |
| `game.gachadnd.openLootTerminal()` | Генератор добычи |
| `game.gachadnd.openShop()` | Магазин на текущем узле |
| `game.gachadnd.openRisk()` | Риск на текущем узле |
| `game.gachadnd.openDoomAltar()` | Алтарь Погибели на текущем узле |
| `game.gachadnd.openMemoryAltar(actor)` | Алтарь Памяти персонажа (Мастер — в любой момент) |
| `game.gachadnd.openDraft()` | окно идущего распределения добычи |
| `game.gachadnd.openStash(actor)` | Хранилище кристаллов персонажа (там же, где Алтарь; Мастер — в любой момент) |
| `game.gachadnd.setRest(true)` / `setRest(false)` | открыть или закрыть Привал без карты; при открытии у игроков открывается Алтарь Памяти |
| `game.gachadnd.setAnchor(true)` / `setAnchor(false)` | открыть или закрыть Якорь (то же, что кнопка Якорь) |
| `game.gachadnd.openGraveyard()` | Кладбище Предела: надгробия персонажей, чьи тела отряд оставил на узле |
| `game.gachadnd.omen('3')` | предвестия Пожирателя у всех: `'3'`, `'2'`, `'1'` — ходов до прихода, `'here'` — пришёл, `'off'` — снять |
| `game.gachadnd.breach()` | прорыв Пожирателя: щелчок по точке на сцене, катсцена у всех, его токен в этой точке |
| `game.gachadnd.openPortal()` | окно портала в Якорь у всех (отряд на Привале) |
| `game.gachadnd.openDeal()` | Сделка луны у всех (отряд на узле Босса, раз за этаж) |
| `game.gachadnd.callEcho()` | Эхо Босса в идущем бою (дар луны этого этажа): окно — кто зовёт и чьё Эхо |
| `game.gachadnd.callDevourer()` | натравить Пожирателя в идущем бою (дар луны этого этажа): щелчок по точке прорыва |
| `game.gachadnd.openResidents('broker')` | окно «Жильцы Якоря»; необязательно — чей прилавок открыть: `smith`, `cartographer`, `broker`, `healer`, `lurer` |
| `game.gachadnd.settleResident('smith')` | поселить жильца в Якоре (Мастер) |
| `game.gachadnd.pulse()` | Пульс отряда: ступень сложности боёв, итог последнего боя, ПЗ отряда |
| `game.gachadnd.scent()` | Запах отряда: `{ value, state, label, thresholds, members }` |
| `game.gachadnd.giveCrystal(actor, 'Имя навыка')` | выдать кристалл навыка |
| `game.gachadnd.recoverUses('gachaRun')` | восстановить заряды «1 раз за забег» |
| `game.gachadnd.eventRewards({ tier: 'notable', count: 3, title: 'Тайник' })` | награды события каждому персонажу отряда; `tier`: `small`, `notable`, `rare`, `floor` |
| `game.gachadnd.openEventRewards()` | окно наград события |

## Настройки модуля

В общем списке — только общие настройки. Частные — в окнах, которые открываются кнопками над ним.

| Общая настройка | Чья | Что делает |
|---|---|---|
| Эффекты модуля | своя у каждого | **Полные**; **Спокойные** — без вспышек, тряски и движения; **Выключены** — без импакт-кадров, катсцены прорыва и сцены редкой добычи, остальное спокойно |
| Громкость модуля | своя у каждого | общая громкость всех звуков модуля |
| Подсказки Мастеру | мира | шёпоты о Запахе и Пульсе и строки атмосферы: модуль напоминает, решает Мастер |
| Автоматизация синергий и навыков | мира | общий выключатель; свои срабатывания каждый игрок настраивает галочками «Вкл.» и «Спрашивать» в окне «Срабатывания синергий и навыков». Попадание модуль не проверяет — бросок урона считается попаданием |
| Сцена Якоря | мира | куда портал и кнопка Якоря переносят отряд; не выбрана — без смены сцены. Новые сцены появляются в списке после перезагрузки мира |
| Грубые названия навыков (18+) | мира | навыки с ненормативной лексикой в названии показываются в исходном виде; выключено — приличные названия. Переключение переименовывает выданные навыки и кристаллы сразу |

| Окно | Что в нём |
|---|---|
| Экономика забега (Мастер) | базовое золото, рост за этаж, цены кристаллов, очистки и обновления, кровь Погибели, компендиумы расходников и магических предметов (по умолчанию `dnd5e.items`) |
| Звуки и эффекты | звуки Терминала (включение, громкость, файлы), папка и файл звука импакт-кадров, тема героя Счётчика ауры и её громкость, замедление импакт-кадров; настройки мира в нём видит только Мастер |
| Подсказки Мастеру (Мастер) | по отдельности: шёпот Запаха Мастеру, строки атмосферы игрокам, шёпот Пульса Мастеру |
| Испытания Риска (Мастер) | свой файл испытаний и «Только свои испытания» |
| Свои названия навыков (Мастер) | по строке на навык: «Название из модуля = Своё название». Хранится в мире и с модулем не распространяется — так столу можно вернуть любимые названия. Выданные навыки и кристаллы (и в Хранилищах) переименовываются сразу; удалите строку — вернётся название модуля |

Журнал Портала для отладки включается макросом `game.gachadnd.portalDebug(true)`.

Номер этажа задаётся на Карте этажа.

## Память и Лабиринт

Модуль состоит из двух частей. **Память** — кристаллы, навыки, синергии, Терминал Тумана, Алтарь Памяти и генератор добычи. **Лабиринт** — карта этажа, экономика, Магазин, Риск, Алтарь Погибели и Всадники. Память работает и без Лабиринта: тогда Привал открывает Мастер командой `setRest`, а золото в добыче не выдаётся.

## Личный эффект

У навыков с личным эффектом (Добро пожаловать ко мне) в Терминале есть кнопка Мастера «Личный эффект»: текст пишется только в копию навыка этого персонажа.
