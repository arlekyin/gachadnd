# Макросы и настройки

Играть можно и без макросов, все основные действия есть на кнопках. Макросы нужны, когда хочешь вызвать что-то вне очереди или починить состояние вручную.

## Макросы

| Команда | Действие |
|---|---|
| `game.gachadnd.openTerminal(actor)` | Терминал Тумана персонажа — панель слева (`toggleTerminal(actor)` — открыть или закрыть; `openTerminalWindow(actor)` — прежнее окно) |
| `game.gachadnd.openMapTerminal()` | Карта этажа |
| `game.gachadnd.openLootTerminal()` | Генератор добычи |
| `game.gachadnd.openShop()` | Магазин на текущем узле |
| `game.gachadnd.openRisk()` | Риск на текущем узле |
| `game.gachadnd.openDoomAltar()` | Алтарь Погибели на текущем узле |
| `game.gachadnd.trade.offer(actor)` | Обмен с персонажем — как правый щелчок игрока по его токену (`trade.list()` — сделки, `trade.show(id)` — окно) |
| `game.gachadnd.openMemoryAltar(actor)` | Алтарь Памяти персонажа (Мастер — в любой момент) |
| `game.gachadnd.openDraft()` | окно идущего распределения добычи |
| `game.gachadnd.openStash(actor)` | Хранилище кристаллов персонажа (там же, где Алтарь; Мастер — в любой момент) |
| `game.gachadnd.setRest(true)` / `setRest(false)` | открыть или закрыть Привал без карты; при открытии у игроков открывается Алтарь Памяти |
| `game.gachadnd.setAnchor(true)` / `setAnchor(false)` | открыть или закрыть Якорь (то же, что кнопка Якорь) |
| `game.gachadnd.openGraveyard()` | Кладбище Предела: надгробия персонажей, чьи тела отряд оставил на узле |
| `game.gachadnd.omen('3')` | предвестия Пожирателя у всех: `'3'`, `'2'`, `'1'` — ходов до прихода, `'here'` — пришёл, `'off'` — снять |
| `game.gachadnd.satiety(1)` | Насыщение Пожирателя ± число (без числа — текущее); эффекты на листе модуль переключает сам |
| `game.gachadnd.syncDevourer({ restore: true })` | заново выставить Глубину и Насыщение на листе Пожирателя; `restore` — ПЗ и легендарные ресурсы на максимум |
| `game.gachadnd.bossRule('muffle')` | правило Босса на текущий бой: `'muffle'` (Глушитель), `'sleepy'` (Крайний спит), список — несколько сразу, `null` — снять |
| `game.gachadnd.scar(actor)` | шрам персонажу; вторым аргументом вид — `'voice'`, `'burn'`, `'crack'` |
| `game.gachadnd.breach()` | прорыв Пожирателя: щелчок по точке на сцене, катсцена у всех, его токен в этой точке |
| `game.gachadnd.openPortal()` | окно портала в Якорь у всех (отряд на Привале) |
| `game.gachadnd.openDeal()` | Сделка луны у всех (отряд на узле Босса, раз за этаж) |
| `game.gachadnd.callEcho()` | Отголосок Босса в идущем бою (дар луны этого этажа): окно — кто зовёт и чей Отголосок |
| `game.gachadnd.callDevourer()` | натравить Пожирателя в идущем бою (дар луны этого этажа): щелчок по точке прорыва |
| `game.gachadnd.openResidents('broker')` | окно «Жильцы Якоря»; необязательно — чей прилавок открыть: `smith`, `cartographer`, `broker`, `healer`, `lurer` |
| `game.gachadnd.settleResident('smith')` | поселить жильца в Якоре (Мастер) |
| `game.gachadnd.openEvent()` | дневник события у всех (отряд на узле «Событие», Мастер) |
| `game.gachadnd.previewEvent('swamp_lights')` | посмотреть событие без узла и без последствий |
| `game.gachadnd.playChronicle(data)` | показать Летопись этажа у себя: `{ oldMap, oldFloor, newMap, newFloor, marks }` (у всех она идёт сама, когда Мастер чертит этаж) |
| `game.gachadnd.pulse()` | Пульс отряда: ступень сложности боёв, итог последнего боя, ПЗ отряда |
| `game.gachadnd.scent()` | Запах отряда: `{ value, state, label, thresholds, members }` |
| `game.gachadnd.giveCrystal(actor, 'Имя навыка')` | выдать кристалл навыка |
| `game.gachadnd.recoverUses('gachaRun')` | восстановить заряды «1 раз за забег» |
| `game.gachadnd.eventRewards({ tier: 'notable', count: 3, title: 'Тайник' })` | награды события каждому персонажу отряда; `tier`: `small`, `notable`, `rare`, `floor` |
| `game.gachadnd.openEventRewards()` | окно наград события |

## Настройки модуля

В общем списке лежат только общие настройки. Частные — в окнах, которые открываются кнопками над ним.

| Общая настройка | Чья | Что делает |
|---|---|---|
| Эффекты модуля | своя у каждого | **Полные**; **Спокойные** — без вспышек, тряски и движения; **Выключены** — без импакт-кадров, катсцены прорыва и сцены редкой добычи |
| Видения Эха | своя у каждого | **Полные**; **Приглушённые** — без пульса, дрожи и мельканий; **Выключены** — остаются шёпоты и наплыв |
| Громкость модуля | своя у каждого | общая громкость всех звуков модуля |
| Подсказки Мастеру | мира | общий выключатель всех шёпотов и строк атмосферы из окна «Подсказки Мастеру» |
| Автоматизация синергий и навыков | мира | общий выключатель. Свои срабатывания каждый игрок настраивает галочками «Вкл.» и «Спрашивать» в окне «Срабатывания синергий и навыков». Попадание модуль не проверяет, бросок урона считается попаданием |
| Сцена Якоря | мира | куда портал и кнопка Якоря переносят отряд; если не выбрана, сцена не меняется. Новые сцены появляются в списке после перезагрузки мира |
| Темнота подземелий | мира | **По встрече**, **Всегда условная** или **Всегда полная**. Полная — видно только освещённое, условная — картинка ночная, но видно всё |
| Грубые названия навыков (18+) | мира | навыки с ненормативной лексикой в названии показываются в исходном виде; если выключено — приличные названия. Переключение сразу переименовывает выданные навыки и кристаллы |

| Окно | Что в нём |
|---|---|
| Экономика забега (Мастер) | базовое золото, рост за этаж, цены кристаллов, очистки и обновления, кровь Погибели, компендиумы расходников и магических предметов (по умолчанию `dnd5e.items`) |
| Звуки и эффекты | звуки Терминала (включение, громкость, файлы), папка и файл звука импакт-кадров, тема героя Счётчика ауры и её громкость, замедление импакт-кадров, звуки паутины, фон арены в бою и его громкость; настройки мира в нём видишь только ты |
| Подсказки Мастеру (Мастер) | по отдельности: шёпот Запаха, строки атмосферы игрокам, шёпот Пульса, дары луны в начале боя, строки счётчиков навыков, кнопки правила Босса, приветствие при первом запуске, встречи на боевых узлах, шёпот об обмене, погода на важных боях, обеты на Элите |
| Испытания Риска (Мастер) | свой файл испытаний и «Только свои испытания» |
| Свои названия навыков (Мастер) | по строке на навык: «Название из модуля = Своё название». Хранится в мире и с модулем не распространяется, так столу можно вернуть любимые названия. Выданные навыки и кристаллы (и в Хранилищах) переименовываются сразу. Удалишь строку — вернётся название модуля |

Журнал Портала для отладки включается макросом `game.gachadnd.portalDebug(true)`.

Номер этажа задаётся на Карте этажа.

## Память и Лабиринт

Модуль состоит из двух частей. **Память** — это кристаллы, навыки, синергии, Огранка, Терминал Тумана, Алтарь Памяти и генератор добычи. **Лабиринт** — это карта этажа, экономика, Магазин, Риск, Алтарь Погибели и Всадники. Память работает и без Лабиринта: тогда Привал открываешь ты командой `setRest`, а золото в добыче не выдаётся.

## Личный эффект

У навыков с личным эффектом (Добро пожаловать ко мне) в Терминале есть твоя кнопка «Личный эффект»: текст пишется только в копию навыка этого персонажа.
