# Схема YAML-навыков

Один файл — один навык. Папка определяет категорию. `node build.mjs` проверяет каждый файл и при любой ошибке останавливает сборку с указанием файла и поля.

| Папка | Категория |
|---|---|
| `anomaly` | АНОМАЛИЯ |
| `damage` | УРОН |
| `defense` | ЗАЩИТА |
| `memory` | ПАМЯТЬ |
| `mobility` | МОБИЛЬНОСТЬ |
| `resource` | РЕСУРС |
| `synergy` | СИНЕРГИЯ |
| `utility` | УТИЛИТА |
| `horseman` | ВСАДНИК |

## Поля

| Поле | Обязательно | Значения |
|---|---|---|
| `id` | да | Ровно 16 латинских букв и цифр. Уникален. Не меняется после публикации. |
| `name` | да | Уникально (без учёта регистра). |
| `rarity` | да | `gray`, `green`, `blue`, `purple`, `red`, `orange` (только всадники) |
| `category` | нет | Если указано — должно совпадать с категорией папки. |
| `tags` | нет | Список тегов из словаря синергий (`scripts/synergy-data.js`). |
| `description` | да | Текст. Пустая строка — новый абзац, одиночный перенос — `<br>`. HTML экранируется. |
| `activation` | нет | `none` (по умолчанию, пассивный навык), `action`, `bonus`, `reaction`, `special`, `minute`, `hour`, `day`, `shortRest`, `longRest`, `encounter`, `turnStart`, `turnEnd`, `legendary`, `mythic`, `lair`, `crew` |
| `uses` | нет | Целое число > 0. Если указан `recovery`, а `uses` нет — 1 заряд. |
| `recovery` | нет | См. таблицу ниже. |
| `range` | нет | Дальность в футах. |
| `target` | нет | `{ type, value }`: шаблон области. `type`: `cone`, `cube`, `cylinder`, `line`, `radius`, `sphere`, `square`, `wall`, `circle`; `value` — размер в футах. |
| `save` | нет | `{ ability, dc, on_save }` — см. ниже. |
| `damage` | нет | Список `{ formula, type }`. |
| `roll` | нет | `{ formula, name }` — бросок для навыка без урона, лечения и спасброска (например, величина снижения урона). Кнопка броска появляется в карточке навыка. В тексте — `{roll}`. |
| `cost` | нет | `{ hp: формула }` — плата ПЗ за использование (например, `'@details.level'`). Списывается автоматически; если ПЗ не хватает, навык не используется. В описании — строка «Цена». |
| `stacking` | нет | `true` — бесконечные ранги: каждое слияние прибавляет значение из единственной записи `damage` (целое число). Несовместимо с `ranks`, только для серых, зелёных и синих. |
| `changes` | нет | Список изменений Active Effect `{ key, mode, value }`. Действуют, только пока навык экипирован в слот. |
| `combat_changes` | нет | Изменения Active Effect, как в `changes`, но действуют, только пока навык экипирован **и** персонаж в начатом бою (штраф Берсерка: КД −2). От ранга не зависят. |
| `slot_bonus` | нет | Целое число > 0. Пока навык экипирован, абсолютный лимит слотов выше на это число. |
| `tagEmitter` | нет | `true` — навык излучает выбранный тег (Сингулярность). |
| `forced_loot` | нет | Целое число > 0. Пока навык экипирован, после каждой генерации добычи персонаж принудительно получает в Память столько случайных кристаллов (Жадность). |
| `drawback` | нет | Текст штрафа. Выводится отдельной строкой в описании. |
| `ranks` | нет | Ранги II и III — см. ниже. |
| `memory_scaling` | нет | Эффект, сила которого зависит от состава Памяти — см. ниже. Действует, только пока навык экипирован. |
| `memory_bonus` | нет | Целое число > 0. Вместимость Памяти больше на это число, пока навык находится в Памяти (экипировать не нужно). |
| `undeletable` | нет | `true` — удалить навык из Памяти может только Мастер; Жадность не сжигает его при переполнении. |
| `combat_swap` | нет | `true` — Горячая замена: в бою снятие навыка тратит заряд этого навыка и разрешает экипировать один навык. Требует `activation` и `recovery`. |
| `personal` | нет | `true` — личный эффект (только `purple`, `red`). В описании появляется блок «Личный эффект: не определён». Мастер вписывает эффект кнопкой «Личный эффект» в Терминале Тумана: текст сохраняется только в копии навыка на листе этого персонажа. |
| `loot_bonus` | нет | Целое число > 0. Пока навык экипирован у персонажа игрока, каждая генерация добычи даёт отряду столько дополнительных кристаллов. |
| `shop_discount` | нет | `{ per_skill, max }` — скидка торговцев в процентах за каждый навык в Памяти, с пределом `max`, пока навык экипирован (Шепард). На магические предметы не действует. |
| `horseman` | нет | Всадник Погибели: `hunger`, `plague`, `war`, `death`. Только при `rarity: orange`. См. ниже. |
| `cleanse` | при `horseman` | Условие сращивания (текст). |
| `cleanse_goal` | нет | Целое число > 0 — сколько нужно для сращивания; прогресс виден в Терминале. |
| `cleansed` | при `horseman` | `{ name, description }` — сращённая форма. |

`range`, `target`, `save`, `damage`, `uses`, `recovery` допустимы только при `activation`, отличном от `none`.

## ranks

Ранг повышается только на Привале: пока отряд стоит на узле «Привал» карты этажа, в Терминале Тумана у навыка с повторным кристаллом в инвентаре появляется кнопка «Слить». Слияние тратит повторный кристалл и Кости Хитов (ранг II — 1, ранг III — 2). Вне Привала повторный кристалл не поглощается и остаётся в инвентаре.

**Правило рангов: ранг меняет только числа, а не суть навыка** (как улучшение карты в Slay the Spire или уровень благословения в Hades).

- Ранги есть только у навыков с числовой основой: заряды, формула урона, лечения или броска, размер области, дальность, значение эффекта.
- Навыки с бинарным или сюжетным эффектом (иммунитет, «нельзя…», шутка, ручное решение Мастера) рангов не имеют.
- Навыки редкости `purple` и `red` уникальны: `ranks` для них запрещён.
- Список из 1–2 элементов: ранг II и ранг III. Ранг наследует значения предыдущего ранга.
- `text` (обязательно) — что даёт ранг. В тексте можно использовать `{damage}` и `{roll}` — формулы этого ранга.
- Можно переопределить только: `uses`, `range`, `target` (размер, не форму), `damage` (формулы, не типы), `roll` (формулу), `changes` (значения тех же ключей).
- Ранг, меняющий только `text`, — ошибка сборки.
- **Эффект первооткрывателя:** игроки видят в описании только полученные ранги. Текст следующего ранга раскрывается сообщением в чате при слиянии. Мастер видит скрытые ранги в Терминале Тумана.

```yaml
uses: 3
damage:
  - formula: 2d4 + @prof
    type: healing
ranks:
  - text: 4 глотка.
    uses: 4
  - text: 5 глотков, лечение 3d4 + бонус мастерства.
    uses: 5
    damage:
      - formula: 3d4 + @prof
        type: healing
```

## memory_scaling

В бою навыки не меняются: экипировать и снимать их можно между узлами карты (исключение — `combat_swap`). Мастер не ограничен.

| Поле | Значения |
|---|---|
| `count` | Что считается: `memory` — навыки в Памяти; `burned` — сожжённые навыки (любое удаление из Памяти, включая сгорание при переполнении); `tag:<тег>` — навыки в Памяти с тегом, включая этот навык; `equipped` — экипированные навыки; `equipped_tag:<тег>` — экипированные навыки с тегом (с учётом излучения Сингулярности); `equipped_not_tag:<тег>` — экипированные навыки без тега; `equipped_tags` — уникальные теги среди экипированных навыков. |
| `offset` | Вычитается из числа: `offset: 1` — «сверх первого». |
| `parity` | `even` или `odd` — эффект действует только при чётном или нечётном числе. |
| `every` | Сила `n` = число / `every`, с округлением вниз. По умолчанию 1. |
| `min` | Эффект действует, только если число ≥ `min`. По умолчанию 1. |
| `max` | Предел `n`: целое число или `prof` (бонус мастерства). |
| `changes` | Изменения Active Effect, как в `changes`. В `value` `{n}` заменяется на силу. |
| `text` | Описание эффекта на персонаже; `{n}` заменяется на силу. |

`memory_scaling` может быть списком таких объектов — каждый создаёт свой эффект (Нумеролог).

Эффект создаётся на персонаже с названием «Навык (n)», пересчитывается при изменении Памяти, экипировки и счётчика сожжённых навыков и виден в панели синергий Терминала.

```yaml
memory_scaling:
  count: tag:яд
  every: 2
  max: 3
  changes:
    - key: system.bonuses.mwak.damage
      mode: add
      value: '+{n}d4[poison]'
```

## Масштабирование

Формулы используют данные персонажа dnd5e:

| Значение | Диапазон 1–20 ур. |
|---|---|
| `@prof` | 2 → 6 |
| `@details.level` | 1 → 20 |
| `(@prof)d6` | 2d6 → 6d6 |
| `@abilities.con.mod` и др. | модификатор характеристики |

## Формулы в тексте

Как в описаниях dnd5e:
- переменные пишутся словами: «восстановите количество ПЗ, равное 1d10 + ваш уровень» (Второе дыхание);
- постоянный урон оформляется кнопкой броска: `[[/damage 1d6 acid]]` → «1d6 урона Кислотой» (Брызги кислоты).

| Запись | Результат |
|---|---|
| `{damage}` | Урон или лечение навыка на текущем ранге. Подставляется при сборке, поэтому описание следует за рангом. Постоянный урон (`1d6` poison) → кнопка броска `[[/damage 1d6 poison]]`, после неё слово «урона» не пишется. Лечение и формулы с переменными → словами: `2d4 + @prof` → «2d4 + бонус мастерства». |
| `{damage}` в `text` ранга | Формула этого ранга — так же, как в описании. |

Перевод переменных: `@prof` → «бонус мастерства», `@details.level` → «ваш уровень», `@abilities.con.mod` → «модификатор Телосложения», `2 * @prof` → «2 × бонус мастерства», `(@prof)d6` → «Nd6…, где N — ваш бонус мастерства». После «равное» первое слагаемое ставится в дательный падеж: «равное бонусу мастерства + ваш уровень».

Число экипированных навыков с тегом доступно в формулах `damage`, `roll` и `cost` как `@flags.gachadnd.counts.<ключ>` и подставляется автоматически. Ключи: аномалия `anomaly`, взрыв `explosion`, движение `movement`, казнь `execution`, кровь `blood`, огонь `fire`, проклятье `curse`, разум `mind`, сталь `steel`, щит `shield`, память `memory`, яд `poison`, свет `light`. В тексте: `(@flags.gachadnd.counts.explosion)d6` → «1d6 за каждый экипированный навык с тегом «взрыв»».

`[[/heal]]` и `[[/damage]]` без формулы запрещены: в карточке чата dnd5e их не разрешает.

Значение, начинающееся с `[[` или `{`, берите в кавычки — иначе YAML прочитает его как список.

## recovery

| Значение | Период dnd5e | Когда восстанавливается |
|---|---|---|
| `short` | `sr` | Короткий и длинный отдых |
| `long` | `lr` | Долгий отдых. По правилам стола он проходит только после босса этажа |
| `day` | `day` | Новый день |
| `turn` | `turn` | Каждый ход в бою (1 раз в ход) |
| `round` | `turnStart` | Начало вашего хода (1 раз в раунд) |
| `combat` | `initiative` | Бросок инициативы (1 раз за бой) |
| `floor` | `lr` | Устаревшее: то же, что `long`. Используйте `long` |
| `run` | `gachaRun` | `game.gachadnd.recoverUses('gachaRun')` |
| `scene` | `gachaScene` | `game.gachadnd.recoverUses('gachaScene')` |
| `none` | — | Никогда |

## save

- `ability`: `str`, `dex`, `con`, `int`, `wis`, `cha`.
- `dc` (по умолчанию `spellcasting`):
  - `spellcasting` — сложность заклинаний персонажа; без заклинательной характеристики — 8 + бонус мастерства;
  - `universal` — 8 + бонус мастерства + наивысший модификатор характеристики;
  - `str` … `cha` — сложность по указанной характеристике;
  - число — фиксированная сложность;
  - `{ formula: "8 + @prof" }` — произвольная формула.
- `on_save`: `half` (по умолчанию), `none`, `full` — урон при успешном спасброске.

## damage

- `formula`: формула броска, например `3d8`, `1 + @prof`.
- `type`: `acid`, `bludgeoning`, `cold`, `fire`, `force`, `lightning`, `necrotic`, `piercing`, `poison`, `psychic`, `radiant`, `slashing`, `thunder`; лечение — `healing`, `temphp`.
- Лечение — только одна запись, без урона и без `save`.

## changes

- `key`: путь в данных актёра, начинается с `system.` или `flags.` (например `system.bonuses.mwak.attack`, `system.skills.ste.roll.mode`).
- `mode`: `add`, `override`, `upgrade`, `downgrade`, `multiply`, `custom`.
- `value`: значение, записывается строкой.

## Пример

```yaml
id: JqCKPHlCBj5lY2B9
name: Фус-Ро-Да
rarity: purple
tags:
  - взрыв
  - движение
description: Каждое существо в 15-футовом конусе совершает спасбросок Силы...
activation: action
recovery: short
target:
  type: cone
  value: 15
save:
  ability: str
damage:
  - formula: 3d8
    type: thunder
```

## Всадники Погибели

Оранжевые навыки с двумя состояниями. Не выпадают в добыче — их выдаёт Алтарь Погибели (узел «Погибель» на карте этажа).

- Проклятый всадник при поглощении сразу экипируется и занимает слот; снять его нельзя.
- Сращённый всадник экипирован сверх лимита слотов. При сращивании описание и имя навыка меняются на сращённую форму, в чат выходит сообщение.
- У персонажа один всадник за забег (флаг персонажа `horseman`).
- Автоматически: Голод сжигает неэкипированные навыки при взятии, принимает кристаллы на корм, пожирает экипированный навык после долгого отдыха без кормления; Война считает серию боевых узлов по карте, ранит носителя на узлах без боя, после сращивания накладывает на отряд Боевой счёт и Кровавую баню.
- Мастер в Терминале: «Прогресс» (+1 к счётчику сращивания) и «Срастить».
