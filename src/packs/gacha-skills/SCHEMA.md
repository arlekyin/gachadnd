# Схема YAML-навыков

Один файл — один навык. Папка определяет категорию. `node build.mjs` проверяет каждый файл и при любой ошибке останавливает сборку с указанием файла и поля.

| Папка | Категория |
|---|---|
| `anomaly` | АНОМАЛИЯ |
| `damage` | УРОН |
| `defense` | ЗАЩИТА |
| `memory` | ПАМЯТЬ |
| `mobility` | МОБИЛЬНОСТЬ |
| `resource` | РЕСУРС |
| `synergy` | СИНЕРГИЯ |
| `utility` | УТИЛИТА |

## Поля

| Поле | Обязательно | Значения |
|---|---|---|
| `id` | да | Ровно 16 латинских букв и цифр. Уникален. Не меняется после публикации. |
| `name` | да | Уникально (без учёта регистра). |
| `rarity` | да | `gray`, `green`, `blue`, `purple`, `red` |
| `category` | нет | Если указано — должно совпадать с категорией папки. |
| `tags` | нет | Список тегов из словаря синергий (`scripts/synergy-data.js`). |
| `description` | да | Текст. Пустая строка — новый абзац, одиночный перенос — `<br>`. HTML экранируется. |
| `activation` | нет | `none` (по умолчанию, пассивный навык), `action`, `bonus`, `reaction`, `special`, `minute`, `hour`, `day`, `shortRest`, `longRest`, `encounter`, `turnStart`, `turnEnd`, `legendary`, `mythic`, `lair`, `crew` |
| `uses` | нет | Целое число > 0. Если указан `recovery`, а `uses` нет — 1 заряд. |
| `recovery` | нет | См. таблицу ниже. |
| `range` | нет | Дальность в футах. |
| `target` | нет | `{ type, value }`: шаблон области. `type`: `cone`, `cube`, `cylinder`, `line`, `radius`, `sphere`, `square`, `wall`, `circle`; `value` — размер в футах. |
| `save` | нет | `{ ability, dc, on_save }` — см. ниже. |
| `damage` | нет | Список `{ formula, type }`. |
| `changes` | нет | Список изменений Active Effect `{ key, mode, value }`. Действуют, только пока навык экипирован в слот. |
| `slot_bonus` | нет | Целое число > 0. Пока навык экипирован, абсолютный лимит слотов выше на это число. |
| `tagEmitter` | нет | `true` — навык излучает выбранный тег (Сингулярность). |
| `forced_loot` | нет | Целое число > 0. Пока навык экипирован, после каждой генерации добычи персонаж принудительно получает в Память столько случайных кристаллов (Жадность). |
| `drawback` | нет | Текст штрафа. Выводится отдельной строкой в описании. |
| `ranks` | нет | Ранги II и III — см. ниже. |

`range`, `target`, `save`, `damage`, `uses`, `recovery` допустимы только при `activation`, отличном от `none`.

## ranks

Ранг повышается двумя путями: повторный кристалл того же навыка (не занимает слот) или кнопка «Улучшить» в Терминале Тумана, пока отряд стоит на узле «Привал» карты этажа (ранг II — 1 Кость Хитов, ранг III — 2; без ограничения числа улучшений). Без `ranks` у навыка один ранг, и повторный кристалл поглотить нельзя.

Навыки редкости `purple` и `red` уникальны: `ranks` для них запрещён.

- Список из 1–2 элементов: ранг II и ранг III.
- `text` (обязательно) — что даёт ранг, выводится в описании.
- Можно переопределить: `uses`, `recovery`, `range`, `target`, `save`, `damage`, `changes`. Значение заменяется целиком (список `damage` или `changes` — полностью).
- Ранг наследует значения предыдущего ранга. Тип активации и теги по рангам не меняются.
- Каждый ранг проверяется как полноценный навык.

```yaml
uses: 3
damage:
  - formula: 2d4 + @prof
    type: healing
ranks:
  - text: 4 глотка.
    uses: 4
  - text: 5 глотков, лечение 3d4 + бонус мастерства.
    uses: 5
    damage:
      - formula: 3d4 + @prof
        type: healing
```

## Масштабирование

Формулы используют данные персонажа dnd5e:

| Значение | Диапазон 1–20 ур. |
|---|---|
| `@prof` | 2 → 6 |
| `@details.level` | 1 → 20 |
| `(@prof)d6` | 2d6 → 6d6 |
| `@abilities.con.mod` и др. | модификатор характеристики |

## Формулы в тексте

Как в описаниях dnd5e:
- переменные пишутся словами: «восстановите количество ПЗ, равное 1d10 + ваш уровень» (Второе дыхание);
- постоянный урон оформляется кнопкой броска: `[[/damage 1d6 acid]]` → «1d6 урона Кислотой» (Брызги кислоты).

| Запись | Результат |
|---|---|
| `{damage}` | Урон или лечение навыка на текущем ранге. Подставляется при сборке, поэтому описание следует за рангом. Постоянный урон (`1d6` poison) → кнопка броска `[[/damage 1d6 poison]]`, после неё слово «урона» не пишется. Лечение и формулы с переменными → словами: `2d4 + @prof` → «2d4 + бонус мастерства». |
| `{damage}` в `text` ранга | Формула этого ранга — так же, как в описании. |

Перевод переменных: `@prof` → «бонус мастерства», `@details.level` → «ваш уровень», `@abilities.con.mod` → «модификатор Телосложения», `2 * @prof` → «2 × бонус мастерства», `(@prof)d6` → «Nd6…, где N — ваш бонус мастерства». После «равное» первое слагаемое ставится в дательный падеж: «равное бонусу мастерства + ваш уровень».

`[[/heal]]` и `[[/damage]]` без формулы запрещены: в карточке чата dnd5e их не разрешает.

Значение, начинающееся с `[[` или `{`, берите в кавычки — иначе YAML прочитает его как список.

## recovery

| Значение | Период dnd5e | Когда восстанавливается |
|---|---|---|
| `short` | `sr` | Короткий и длинный отдых |
| `long` | `lr` | Длинный отдых |
| `day` | `day` | Новый день |
| `turn` | `turn` | Каждый ход в бою (1 раз в ход) |
| `round` | `turnStart` | Начало вашего хода (1 раз в раунд) |
| `combat` | `initiative` | Бросок инициативы (1 раз за бой) |
| `floor` | `lr` | Долгий отдых. По правилам стола он проходит только после босса, поэтому «раз за этаж» = «раз за долгий отдых» |
| `run` | `gachaRun` | `game.gachadnd.recoverUses('gachaRun')` |
| `scene` | `gachaScene` | `game.gachadnd.recoverUses('gachaScene')` |
| `none` | — | Никогда |

## save

- `ability`: `str`, `dex`, `con`, `int`, `wis`, `cha`.
- `dc` (по умолчанию `spellcasting`):
  - `spellcasting` — сложность заклинаний персонажа; без заклинательной характеристики — 8 + бонус мастерства;
  - `universal` — 8 + бонус мастерства + наивысший модификатор характеристики;
  - `str` … `cha` — сложность по указанной характеристике;
  - число — фиксированная сложность;
  - `{ formula: "8 + @prof" }` — произвольная формула.
- `on_save`: `half` (по умолчанию), `none`, `full` — урон при успешном спасброске.

## damage

- `formula`: формула броска, например `3d8`, `1 + @prof`.
- `type`: `acid`, `bludgeoning`, `cold`, `fire`, `force`, `lightning`, `necrotic`, `piercing`, `poison`, `psychic`, `radiant`, `slashing`, `thunder`; лечение — `healing`, `temphp`.
- Лечение — только одна запись, без урона и без `save`.

## changes

- `key`: путь в данных актёра, начинается с `system.` или `flags.` (например `system.bonuses.mwak.attack`, `system.skills.ste.roll.mode`).
- `mode`: `add`, `override`, `upgrade`, `downgrade`, `multiply`, `custom`.
- `value`: значение, записывается строкой.

## Пример

```yaml
id: JqCKPHlCBj5lY2B9
name: Фус-Ро-Да
rarity: purple
tags:
  - взрыв
  - движение
description: Каждое существо в 15-футовом конусе совершает спасбросок Силы...
activation: action
recovery: short
target:
  type: cone
  value: 15
save:
  ability: str
damage:
  - formula: 3d8
    type: thunder
```
