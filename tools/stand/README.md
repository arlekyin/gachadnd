# Стенды анимаций

Импакт-кадры и их звуки проверяются без Foundry: стенд открывает страницу с настоящим кодом модуля
в Chromium, подменяет Foundry минимальной заглушкой, управляет временем и сохраняет снимки.
Так любую правку анимации видно покадрово за минуту, не запуская мир.

## Подготовка

```
npm install
npx playwright install chromium
```

`pixi.js` 7.4.2 — та же версия, что в Foundry v12–13; Playwright управляет браузером.

Параметры:

- `--calm` — спокойный режим (без вспышек и инверсии), у всех стендов с картинкой.
- `--at=300,1760` — снимки только в эти моменты, мс от начала (кулаки, Сайтама).
- `--until=2060` — остановить Сайтаму раньше конца.
- `--h` — горизонтальный разрез; `--dpr=1.25` — масштаб экрана Windows 125%; `--slow=100` — замедление разреза.

Порядок для звука: сначала `saitama.mjs` (пишет журнал моментов), потом `sound.mjs`.

## Как устроено

- `harness.mjs` — статический сервер от корня репозитория (страницы импортируют `/scripts/...`, как в Foundry), Chromium с программным WebGL, снимки.
- `clock.js` — ручное время: `requestAnimationFrame` копит кадры, `step(мс)` отрисовывает кадр в заданный момент. Анимация идёт кадрами по 16 мс, сколько бы ни считал медленный программный WebGL.
- `foundry-mock.js` — настройки, хуки, сокет; `?calm`, `?slow=N` в адресе.
- `field.js` — поле для навыков: окна без шаблонов, документы сцены (плитки, токены с `updateToken`), стены `window.WALLS`, персонаж с навыком и `useSkill()`; `?v13` — движение Foundry v13 (`TokenDocument#move`, хук `moveToken`).
- `scene.js` — сцена PIXI как в Foundry: пол 1134×1192 с сеткой, камера, токены из `assets/bestiary` с `mesh` и `effects`.
- Разрез идёт в реальном времени, замедленный в `slow` раз: его кадр завязан на таймеры, а не только на кадры.

Программный WebGL медленный: полный прогон Сайтамы — около двух минут, разреза — около полуминуты на вариант.
