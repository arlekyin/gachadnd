# Симулятор боя с Пожирателем

Монте-Карло: бой прогоняется тысячи раз со случайными бросками, отчёт — доли исходов. Только числа: без позиционирования и тактики.

```
node tools/sim/devourer.mjs                      отряд из tools/sim/party, все Глубины 1–10 и Насыщения 0–5
node tools/sim/devourer.mjs --level 5            типовой отряд 5 уровня (боец, плут, жрец, волшебник), если папка пуста
node tools/sim/devourer.mjs --depth 3            одна Глубина, все Насыщения
node tools/sim/devourer.mjs --depth 3 --satiety 1 --runs 10000
node tools/sim/devourer.mjs --depth 3 --log      один бой по ходам
```

Отчёт печатается и сохраняется в `tools/sim/last-run.txt`. Профиль Пожирателя берётся из `tools/bestiary.mjs` — после правки бестиария прогон сразу считает новые числа.

## Что моделируется

- **Пожиратель:** КД, ПЗ, попадание, урон и Сл по Глубине и Насыщению; Шов (ходит первым на счёте 20); Нюх (преимущество по носителю самого большого запаса); Мультиатака (3 атаки с Глубины 5); Укус глотает кристалл при провале Ловкости; Брюхо — уходит, когда вес дошёл до 3 + Насыщение; Слои памяти (за раунд рушится один слой, урон сверх границы пропадает); Адаптация (сопротивление, повторно — иммунитет; с Глубины 6 — два типа); Отрыжка; Перекрутка (переброс первого попадания за раунд); легендарные действия (Коготь) и сопротивления; логово (Кристаллы гудят); кость Памяти к6/к8/к10 с выбором из двух бросков с Насыщения 2; ранги навыков; Последний слой на Глубине 10.
- **Огрызки:** выхватывают кристаллы и несут в Брюхо; персонаж может сбить Огрызка с кристаллом.
- **Навыки Памяти и синергии:** включённые эффекты актёра и экипированных навыков (КД, характеристики, бонусы к атаке и урону, Сл, спасброски, сопротивления, перегрузка); способности синергий и навыки с уроном или лечением; срабатывания — доп. урон «1 раз в ход» с условиями, лечение после урона, реакции на урон (уменьшение, Уно-реверс), плата уроном за преимущество, Кровавый пакт. Навыки без чисел (контроль, перемещение, утилиты) не участвуют — отчёт перечисляет их у каждого персонажа.
- **Отряд:** каждый ход — лучший по среднему урону вариант (оружие с доп. атаками, заговоры, заклинания с ячейками, экипированные навыки Памяти с зарядами) и бонусное действие; скрытая атака плута; лечение лежащего союзника важнее урона. Ограниченные ресурсы тратятся, как только выгоднее бесплатного варианта.

## Упрощения

- Нет позиций: все в досягаемости, области задевают 2–3 персонажа.
- Навыки Памяти Пожирателя — по среднему эффекту: урон, испуг, помеха, потерянный ход, отменённое действие (ЗА ВАРУДО).
- Нет концентрации, длительных эффектов, реакций игроков, спасбросков от смерти: упавший персонаж выбывает, пока его не вылечат.
- Срабатывания считаются включёнными у всех: личные галочки игроков в экспорт не попадают. Плата уроном за преимущество берётся, пока у персонажа больше половины ПЗ.
- Эффекты «только в бою» (штраф Берсерка) и масштабирование по числу тегов считаются, только если они уже записаны в эффектах актёра на момент экспорта.
- Переварить (лечение Пожирателя от Брюха) и Откуп не используются.
