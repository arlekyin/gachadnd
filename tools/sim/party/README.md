# Персонажи для симулятора

1. В Foundry: вкладка «Актёры» → правый клик по персонажу → **Export Data**. Сохраняется файл `fvtt-Actor-….json`.
2. Положите файлы всех персонажей отряда в эту папку (`tools/sim/party/`).
3. Запустите из корня модуля: `node tools/sim/devourer.mjs`.

Экспорт хранит данные листа, но не то, что dnd5e досчитывает при загрузке мира: активные эффекты, синергии, бонусы предметов к КД и урону. Если в начале отчёта у персонажа неверные КД или ПЗ — впишите поправку в `overrides.json` рядом с экспортом:

```json
{
  "Имя персонажа": { "ac": 18, "hp": 45, "hit": 1, "damage": 2, "crystals": [1, 2, 3] }
}
```

`hit` и `damage` прибавляются ко всем атакам и урону персонажа, `crystals` — веса кристаллов в инвентаре (серый и зелёный — 1, синий — 2, фиолетовый — 3, красный — 5). Поля необязательны.

Файлы экспорта в git не попадают (`.gitignore`): это данные ваших игроков.
