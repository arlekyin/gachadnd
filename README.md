# Gacha Roguelike для D&D 5e

**Рогалик-забег для dnd5e на вечер — без подготовки Мастера.** Отряд спускается по этажам Лабиринта: карта
чертится сама, на узлах ждут бои, события, Магазин и риски, в центре — Босс, а по пятам идёт Пожиратель.
Между этажами — Якорь, где герои меняют навыки и залечивают шрамы. Умереть можно; сжечь навык — тоже.

Модуль для [Foundry VTT](https://foundryvtt.com/) и системы dnd5e. **Язык — русский.**

> Это альфа. Числа и баланс пока прикинуты на своём столе — отзывы и ошибки очень ждём (см. «Обратная связь»).

## Что внутри

- **Память и кристаллы.** Около 200 навыков Тумана с автоматизацией: выпадают кристаллами, крутятся как гача,
  занимают слоты. Каждый навык — штатная карточка dnd5e в чате и видимые броски.
- **Синергии и связки.** Навыки одного тега дают ступени; пары тегов — особые способности.
- **Огранка.** Ступени синергий дают камни, которые меняют, как работают способности вашего класса: бить по
  нескольким целям, закладывать миной, платить кровью вместо ячейки.
- **Карта этажа.** Ряды или паутина вокруг Босса, Застава, Запах и Насыщение, Пожиратель, который идёт за отрядом.
- **Якорь.** Алтарь Памяти, Хранилище кристаллов, жильцы, портал на Привале.
- **Босс и его правила**, шрамы, перегрев, Эхо, события-дневник, Летопись этажа, Магазин и риски.
- **Терминал Тумана** — вся сборка героя одним слоем рядом с картой.

Мастер решает, модуль считает: подсказки Мастеру отключаются в настройках, а там, где нужен выбор, — кнопки
у Мастера, а не автоматика.

## Установка

В Foundry: **Add-on Modules → Install Module**, вставьте ссылку на манифест и нажмите **Install**:

```
https://github.com/arlekyin/gachadnd/releases/latest/download/module.json
```

Включите модуль в мире на системе dnd5e.

## Совместимость

- Foundry VTT **v13–v14** (проверяется на v14).
- Система **dnd5e 5.2–6.x**.
- Рекомендуется **[Impact Frames](https://github.com/arlekyin/impact-frames)** — без него у одного ультимейта нет
  анимации удара (сам навык работает).
- Рекомендуется **[Token Choreography](https://github.com/arlekyin/token-choreography)** — анимации токенов. Рогалик
  работает и без него. Если у вас уже стоит другой модуль анимации токенов, его можно не ставить: они могут конфликтовать.
  Оба модуля Foundry предложит при установке, галочки можно снять.
- Для русского интерфейса Foundry — модуль [Russian Translation](https://foundryvtt.com/packages/ru-ru/).

## С чего начать

1. Игроки делают героев 1 уровня, а Мастер назначает каждому его героя («Настройка участника»). Нет времени — игроку
   без персонажа в окне «Новый забег» можно выбрать готового героя 1 уровня из dnd5e.
2. Мастер жмёт **«Новый забег»** — кнопку с флажком на панели токенов (при первом запуске она же приходит шёпотом
   в чат). Одно окно: отряд, карта, Якорь — «Начать». Модуль чертит первый этаж, открывает Якорь и страницу
   **«Первый забег»** — шесть шагов до Босса этажа.
3. Игрокам в чат приходит **«Памятка»** — одна страница. Терминал Тумана (навыки, синергии, Огранка) открывается
   кнопкой на панели.
4. Бои готовить не нужно: на боевом узле Мастеру приходит встреча из SRD dnd5e — «На арену» строит поле боя.

## In English

**A roguelike run mode for D&D 5e in Foundry VTT, with no GM prep.** Descend the floors of the Labyrinth on a
generated map, collect ~200 automated skills from gacha crystals, build synergies, reshape your class abilities
with gems, and outrun the Devourer. **The module is in Russian only for now.** Install with the manifest URL
above; Foundry v13–v14, dnd5e 5.2–6.x. Code MIT, content CC BY-NC 4.0. Code and most texts were written with AI
assistance; skill icons and some art are AI-generated.
