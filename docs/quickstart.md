# Быстрый старт: первый забег за 5 минут (черновик на утверждение)

**Цель.** Незнакомый Мастер поставил модуль, игроки сделали героев 1 уровня. Через 5 минут отряд стоит на
первом узле, а через 10 — в первом бою. Без чтения справочника целиком и без подготовки сцен и монстров.

## Что мешает сейчас

1. **Нет точки входа.** Правила лежат в двух компендиумах. Где начать — «Карта этажа» на панели, Якорь, Терминал, —
   Мастер узнаёт, только прочитав «Как вести забег».
2. **Сцены нужно делать самому.** Карту этажа чертят на какой-то сцене; сцену Якоря — тоже самому (или без неё).
3. **Бои — главная подготовка.** На узлах Монстры, Элита, Застава и Босс модуль ничего не открывает: монстров,
   их силу и карту боя Мастер собирает сам на каждый бой. Это прямо расходится с обещанием README «без подготовки».
4. **Игрокам нечего прочитать за минуту.** Правила игрока — несколько страниц.

Что уже работает само: Пожиратель импортируется из бестиария при первом прорыве; добыча, Магазин, Риск, события,
Якорь, Сделка луны открываются у всех сами.

## Предложение: три части

### 1. «Новый забег» — одно окно Мастера

Кнопка на панели модуля (видна только Мастеру). При первом запуске модуля в мире — шёпот Мастеру с этой кнопкой;
шёпот отключается в настройках, как остальные подсказки Мастеру.

Одно окно, не пошаговый мастер:
- **Отряд** — персонажи игроков галочками (по умолчанию — все персонажи, у которых есть игрок). Рядом — уровень
  каждого; если не 1, строка «забег рассчитан на 1 уровень» — решение за Мастером.
- **Карта** — ряды или паутина; для рядов — длина (по умолчанию 11).
- **Якорь** — «без сцены» (по умолчанию), «создать простую сцену» или «своя сцена».
- **Начать** →
  - сцена «Лабиринт: этаж 1» (тёмная подложка в стиле Тумана), этаж начерчен, Мастер на ней;
  - если выбран — сцена Якоря;
  - отряд в Якоре: у игроков открывается Алтарь Памяти (как кнопка «Якорь» сейчас);
  - у Мастера открывается журнал «Первый забег», у игроков — «Памятка».

Повторно окно можно открыть в любой момент: «Новый забег» поверх старого спрашивает, сохранить ли старую карту.

### 2. «Бой на узле» — встреча, которую предлагает модуль

Отряд вошёл на боевой узел — Мастеру приходит **готовая встреча** (шёпот с кнопками или небольшая панель):

| Узел | Сила встречи (бюджет опыта dnd5e на отряд) |
|---|---|
| Монстры | средняя |
| Элита | тяжёлая |
| Застава | тяжёлая на уровень отряда + 1 (как сейчас в правилах) |
| Босс | смертельная; сверху — правила Босса, как сейчас |

- **Монстры — из компендиума dnd5e** (SRD, есть у каждого стола): по бюджету, числу героев и **биому этажа**
  (болото — звери, нежить, феи; город — люди и культисты; и так далее — таблица на биом).
- Кнопки: **«На арену»** — генератор арен строит поле боя, отряд слева, враги справа; **«На эту сцену»** — враги
  у края текущей сцены; **«Другой состав»**; **«Сам»** — модуль ничего не ставит.
- Инициатива — штатной кнопкой dnd5e. Встреча — предложение: Мастер может заменить любого монстра.
- Добыча после боя — как сейчас, Генератором добычи.

Это и есть «без подготовки»: сейчас именно этого шага нет.

### 3. Две страницы вместо справочника

- **Журнал Мастера «Первый забег»** — одна страница, 6 шагов: «Новый забег» → Якорь → первый шаг по карте → бой
  (кнопки встречи) → добыча → Застава и Босс. Со ссылками на нужные главы Справочника.
- **«Памятка» игроку** — одна страница: Терминал Тумана, кристаллы и слоты, синергии, тело погибшего, Якорь.
- Объяснения — только в журналах; в интерфейсе подсказок по сборке нет, как и договаривались.

## Порядок и объём

1. «Новый забег» и две страницы — 1–2 сессии.
2. «Бой на узле» — 2–3 сессии: бюджет опыта, таблицы монстров на биомы, расстановка, проверка.

Предлагаю делать по порядку: первое даёт вход, второе — само обещание «без подготовки».

## Решено (23.10.2026)

- **Встречи делаем**, монстры — из SRD dnd5e.
- **Демо — один этаж**, поэтому арене хватает нынешнего биома (лес с болотом); новые биомы — потом.
- **Уровень отряда** — только предупреждать, если не 1.
- **Порядок:** сначала «Новый забег», потом встречи, потом две страницы.
