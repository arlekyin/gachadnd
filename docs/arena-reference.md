# Арены этажа: что видно в готовых сценах (разбор)

Разобраны 9 наборов боевых карт Czepeku из купленных автором (только для изучения приёмов; их арт и данные в модуль не
входят — лицензия личная): Wyrm Nest, Verem Cellars, Dark Woods Edge, Mangrove Forest, Swamp Graveyard, Mushroom
Infested Mines, Lich Catacomb, Desert Ruins, Siren's Shipwreck Shore, Slum District — всего 199 сцен.

## Устройство набора

- **Одна планировка — 14–33 варианта.** День, ночь, туман, дождь, зима, засуха, разлив, кровь, порча, токсины,
  «без яиц», «пустыня» и т. п. Отличается только картинка и цвет света; стены и расположение источников почти всегда
  те же. Это готовая основа для «настроения» арены по состоянию этажа.
- **Размер:** от 22×17 до 66×50 клеток; клетка 140 px. Обычно 26–42 клетки по короткой стороне.
- **Темнота сцены всегда 0, глобальный свет включён.** Ночь нарисована в картинке, а не сделана освещением Foundry.

## Свет: тень, а не освещение

- **«Живая муть»:** десятки тусклых светильников тёмного цвета (alpha 0,5, анимация «призрак», без яркого радиуса).
  Ставятся на тёмные места картинки — воду, топь, ямы, тень под деревьями: вода «дышит», карта оживает, хотя ничего
  не светится. Цвет — от варианта: кровь — тёмно-красный, порча — болотный, мирный — тёмная бирюза, дождь — серый.
- **Марево:** 2–7 огромных светильников с анимацией «туман» (dim 25–75 клеток, alpha 0,2) — пустыня, засуха, дым.
- **Настоящие огни** — только в ночных и «огненных» вариантах и в помещениях: факелы и свечи (анимация «факел»,
  bright 1–6, dim 2–15), часто кучками по 3–5 свечей. «Светлячки» — сотня крошечных факелов (dim 3,5).
- **Особые источники:** «пульс» для магии и грибов, «эманация» для ритуального круга, «звёздный свет» для блеска.

## Стены

- **Открытая местность** — стен почти нет, кроме «ограниченного обзора» (sight 10): кольца вокруг крон деревьев,
  кусты, края обрывов. Деревья — маленькие замкнутые многоугольники ограниченного обзора.
- **Помещения и руины** — обычные стены по краю нарисованной кладки, двери единицами, тайные двери — по одной на
  набор. Пещеры — длинные ломаные по краю породы (Mushroom Mines — до 900 отрезков).

## Что из этого берём для генератора арен

1. **Вариант по состоянию этажа**, а не случайно: Пожиратель рядом — «Туман»/«Порча», Босс набрал ступени —
   «Кровь», Привал — «Мирный», высокий Пульс — «Токсины», ночь этажа — ночной вариант.
2. **«Живая муть» автоматически** для любой карты: найти тёмные области фона (вода, ямы, тени) и поставить над ними
   тусклые светильники «призрак» в цвет биома и состояния. Без яркого радиуса и без темноты сцены.
3. **Марево** 2–4 большими светильниками «туман» для пустынь, засухи, дыма Предела.
4. **Арены — из наборов Мастера:** модуль ничего не копирует, а берёт установленные у Мастера сцены (биом по
   названию: Forest, Swamp, Cellar…), их вариант и стены; отряд — у входной кромки, враги — по встрече.
