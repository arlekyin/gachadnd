# Модуль синематики: импакт-кадры решающего удара

> **Решение от 22.10.2026:** модуль не развиваем. impact-frames — вынесенные из gachadnd кадры удара и библиотека
> сцен; добивания будут в token-choreography. От модуля в gachadnd зависит только удар Сайтамы («Серия обычных
> ударов»): анимацию играет `api.launch`, без модуля навык только отбрасывает цель. Автокадры на решающие удары
> любых атак (шаги 1–2 ниже) остались в модуле, но выключены по умолчанию. Остальное ниже — первоначальный замысел.

Отдельный модуль Foundry из того, что уже есть в gachadnd: библиотеки сцен (`scripts/cutscene/`, ~870 строк) и
импакт-кадров (`scripts/memory/effects/impact-*`, ~2950 строк). Сейчас кадры показывают только три ультимейта
gachadnd и рухнувший слой Пожирателя. Модуль научит их срабатывать на **любой решающий удар dnd5e** и даст Мастеру
простые сцены без кода.

## Зачем

- **Ниша свободна.** Сюжетные врезки в духе JRPG — у Cinematic Cut-ins (Patreon), заставка Босса под музыку —
  у Boss Beat, анимации ударов — у Automated Animations и Animater, «весомость боя» обещает Aeris Animations,
  кровь на поле — Splatter, тряска — FX Bus. **Стоп-кадра на решающий удар** — хитстопа, как в файтингах и аниме, —
  нет ни у кого.
- **Единственный из наших модулей, который пройдёт в официальный каталог Foundry** (правила об ИИ от 18.03.2026):
  код, процедурная графика и синтезированный звук разрешены. gachadnd, генератор арен и token-choreography опираются
  на сгенерированный арт и туда не попадут. Каталог — это видимость.
- **Почти готов:** библиотека сцен ничего не берёт из gachadnd, кадры работают и проверены.

## Название

Пакеты Foundry называют латиницей через дефис. Предлагаю **`impact-frames`**, название — «Impact Frames — кадры
решающего удара (dnd5e)». Другие варианты: `hitstop`, `decisive-blow`. Решение за вами.

## Что видят игроки

**Решающий удар.** Урон применён, и он решает исход — модуль на долю секунды подменяет экран у всех за столом:
застывшая сцена с рывком камеры к точке удара (хитстоп), затем два кадра — фигуры бьющего и цели силуэтами,
фон в штрихах от точки удара, второй кадр — инверсия. Звук — синтез в браузере, без файлов.

Что считается решающим (каждое — переключатель, пороги — настройкой Мастера):
- цель погибла (0 ПЗ);
- критическое попадание;
- урон за раз — не меньше половины максимума ПЗ цели;
- последний враг в бою.

Чтобы не приелось: не чаще одного кадра за ход (настройка), только по ударам героев игроков или также по ударам
монстров (настройка; по умолчанию — героев).

**Стили кадра** — по типу урона, Мастер может задать свой стиль предмету или персонажу:

| Стиль | Когда по умолчанию | Что происходит |
|---|---|---|
| **Стоп-кадр** | всё остальное | хитстоп и две инверсные карточки с силуэтами |
| **Разрез** | рубящий урон | сцена в контрастном ч/б рассекается по линии удара, половины разъезжаются, токены — силуэты с обводкой |
| **Серия ударов** | дробящий урон без оружия | экран темнеет, в экран летят пять ударов с трещинами, пылью и негативом, белая вспышка |
| **Отброс** | только вручную или по API | наезд камеры, вдох, рывок, вспышка, цель улетает с пылью и трещинами при приземлении |

В gachadnd «Серия ударов» и «Отброс» — один ультимейт с прямой отсылкой; в модуле они без отсылок и без
фирменной реплики. Сдвиг токена при Отбросе меняет положение на поле, поэтому по умолчанию он **только зрелище**: токен
возвращается на место. Настройка Мастера «Отброс двигает токен» переносит его по-настоящему.

**Доступность** — у каждого игрока свой режим: полный / без вспышек (без белой вспышки, инверсии и тряски) /
выключено. Учитывается системная настройка «меньше движения». Замедление показа (×1–×30) — чтобы рассмотреть кадр.

## Сцены для Мастера без кода

Небольшое окно и макросы, «сыграть у всех» или «только себе»:
- наезд камеры на токен или точку, поворот, тряска;
- кинополосы; сцена в ч/б или негатив;
- волны по экрану (шейдер);
- приглушить музыку, провал в тишину;
- импакт-кадр по выбранным токенам вручную — для сюжетного момента.

Сцены собираются из тех же частей, что и кадры: камера, полосы, фильтры, холсты поверх экрана, звук.

## Для разработчиков

API через `game.modules.get('impact-frames').api`:
- `play({ style, attacker, target, point })` — кадр сейчас у всех;
- `arm(actor, options)` — взвести кадр на следующий решающий урон этого персонажа;
- части сцен: `camera`, `letterbox`, `stage`, `overlay`, `audio` — как сейчас в `scripts/cutscene/`.

Хук `impactFrames.preplay` — чтобы другой модуль отменил или поменял кадр.

## Что остаётся в gachadnd

- Сюжетные сцены: прорыв Пожирателя, портал, предвестия, переходы между сценами, QTE, свет навыков — на своей
  копии библиотеки. gachadnd ни от чего не зависит, как и договорились с анимациями.
- Ультимейты с кадром: если модуль кадров установлен — gachadnd отдаёт кадр ему (`api.arm`), если нет — играет
  свой, как сейчас.

## С чем уживается

- **Dice So Nice** — кадр ждёт, пока кубики докатятся.
- **Automated Animations, Animater** — кадр после их анимации удара, а не поверх.
- **token-choreography** — хореография двигает тело при ударе, кадр ставит точку; модули зовут друг друга через API,
  если оба стоят.
- Совместимость: Foundry v13–v14, dnd5e 5.2–6.x. Другие системы (PF2e) — позже: камера и сцены от системы не
  зависят, распознавание решающего удара — зависит.

## Решено

- **Название** — `impact-frames`, «Impact Frames — кадры решающего удара (dnd5e)».
- **Кто бьёт** — урон связывается с сообщением броска: у карточки dnd5e есть бьющий. Проверить на v13 и v14.
- **Отброс** — есть настройка, которая двигает токен по-настоящему; без неё Отброс — только зрелище.
- **Тексты** — README и подписи пока пишу я черновиком; потом автор переписывает их сам (для каталога).
- **Цена** — бесплатно.
