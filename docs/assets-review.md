# Ассеты: происхождение и права

Ревизия 2026-10-17: все 26 файлов `assets/` и пути, по которым модуль берёт картинки и звуки из Foundry и dnd5e.
Метаданных об авторстве (EXIF, XMP, следов генератора) нет ни в одном файле — происхождение со слов автора модуля.
Не юридическая консультация.

| Файлы | Откуда | Статус |
|---|---|---|
| `icons/skills/*_fog_active.webp`, `*_fog_crystall.webp` (12, иконки всех навыков и кристаллов) | сгенерированы автором модуля; оранжевые — перекраска красных | можно публиковать, если условия генератора разрешают публикацию результатов — проверить тариф/условия |
| `bestiary/devourer.png` (оригинал), `devourer.webp`, `devourer-token.webp` (токен вырезан из портрета) | сгенерирован автором модуля по текстовому описанию (23.10.2026); генератор разрешает коммерческое использование, без указания авторства и роялти | можно |
| `battlemap/forest/*` (текстуры и спрайты арен) | сгенерированы автором модуля по промптам из `docs/battlemap-*.md` (23.10.2026 — подтвердить у автора) | можно, если условия генератора разрешают |
| `sketches/*` (зарисовки событий) | сгенерированы автором модуля по промптам из `docs/sketch-prompts.md` (подтвердить у автора) | можно, если условия генератора разрешают |
| `battlemap/weapons/*` | спрайты оружия для модуля token-choreography; в выпуск gachadnd не входят | — |
| `fonts/caveat/*` | шрифт Caveat, SIL OFL; `OFL.txt` рядом | можно |
| `portal/*.svg`, `tetris/block.svg` | нарисованы кодом в модуле | можно |
| `bestiary/chess-*.webp` | знак шахматной фигуры на диске, отрисован кодом в модуле | можно |
| `icons/svg/…`, `icons/magic/…`, `icons/creatures/…`, `sounds/*.wav`, `systems/dnd5e/icons/…` | ассеты Foundry и dnd5e, модуль ссылается по пути и не распространяет | можно |
